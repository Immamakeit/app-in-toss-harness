# SDK 기능 매트릭스: 현재 RN 프로젝트 기준

## 목적

이 문서는 공식 SDK 개요 문서의 `한 눈에 보기` 표를
**현재 프로젝트가 React Native 기반 Apps in Toss SDK 앱이라는 전제**에서 다시 분류한 참조 문서다.

판단 기준은 아래와 같다.

- 현재 프로젝트 런타임: `RN`
- 공식 표의 `지원 환경`
- 공식 표의 `추천 대상`
- 이미 정리해 둔 서버 연동 문서

## 먼저 결론

`@apps-in-toss/framework`를 쓰고 있으므로 Apps in Toss SDK 기능군을 사용할 수 있는 기반은 맞다.
하지만 **표에 있는 기능이 전부 지금 당장 자동으로 다 되는 것은 아니다.**

다음으로 나뉜다.

1. RN에서 바로 검토 가능한 기능
2. RN에서 가능하지만 권한/콘솔/서버/플랫폼 제약이 붙는 기능
3. RN 프로젝트에서는 제외되는 기능

## 현재 프로젝트 근거

- SDK: `@apps-in-toss/framework`
- Granite RN 사용
- 앱 등록: `AppsInToss.registerApp(...)`

## 2. RN에서 가능하지만 조건이 붙는 기능

아래 기능들은 RN에서 지원되더라도, 실제 사용에는 별도 전제가 필요하다.

| 기능군 | 기능 | 추가 전제 |
| --- | --- | --- |
| 인증 | 토스 로그인 - 인가 코드 받기 | 서버 + mTLS + 토큰 저장/복호화 처리 |
| 인증 | 토스 로그인 연동 확인 | 게임 로그인/마이그레이션 문맥 확인 필요 |
| 인증 | 게임 로그인 - 유저 식별자 받기 | 게임 서비스일 때만 실질 대상 |
| 인증 | 토스 인증 - 인증 화면 호출 | 인증 기획 + 서버 처리 + 정책 검토 필요 |
| 결제 | 토스 페이 | 서버 + mTLS + `x-toss-user-key` + 주문/결제/환불/상태조회 구현 |
| 결제 | 인앱 결제 | 상품 등록 + 지급 로직 + 주문 복원 + 샌드박스 테스트 |
| 광고 | 전면형/리워드 광고 | 광고 상품/정책/테스트 경로 확인 필요 |
| 광고 | 배너 광고(React Native) | 광고 상품/정책/테스트 경로 확인 필요 |
| 광고 | 인앱 광고 2.0 | 광고 상품/정책/테스트 경로 확인 필요 |
| 프로모션 | 프로모션(토스 포인트) | 게임/비게임 구분 + 중복 지급 방어 + 콘솔 설정 |
| 공유 | 공유 리워드 | 리워드 정책 + 중복 지급/남용 방지 설계 필요 |
| 권한 | 필요한 권한 설정하기 | `granite.config.ts` 선언 + 권한 UX + 거부 시 대체 흐름 |
| 위치 | 현재 위치 가져오기 | 위치 권한 필요 |
| 위치 | 실시간 위치 추적하기 | 위치 권한 + 배터리/백그라운드 정책 고려 |
| 위치 | 훅으로 위치 사용하기 | 위치 권한 필요 |
| 카메라/사진 | 카메라로 사진 촬영하기 | 카메라 권한 필요 |
| 카메라/사진 | 앨범 가져오기 | 사진 권한 필요 |
| 연락처 | 연락처 가져오기 | 연락처 권한 필요 |
| 네비게이션/OS | 외부 URL 열기 | 허용 가능한 외부 링크인지 정책 검토 필요 |
| 화면 제어 | 화면 방향 설정하기 | 게임 문맥에서 더 적합 |
| 화면 제어 | 화면 항상 켜짐 설정하기 | 게임 문맥에서 더 적합 |
| UI | BlurView | iOS 전용 |
| 인터랙션 | 오디오 포커스 변경 콜백 | RN 지원이지만 게임/미디어 UX에서 주로 의미 있음 |

### 서버가 붙어야 하는 대표 기능

아래는 RN에서 호출 가능하더라도 **서버 연동 없이는 완결되지 않는 기능**이다.

- 토스 로그인
- 토스 페이
- 인앱결제 상태 조회
- 스마트 메시지
- 프로모션 Server-to-Server

참조:

- `common-protocol.md`
- `login.md`
- `tosspay.md`
- `iap.md`
- `smart-message.md`
- `promotion.md`

### 콘솔 설정이 중요한 기능

- 앱 내 기능
- 인앱결제 상품
- 프로모션
- 메시지 템플릿
- 권한 설정

### 게임 기획일 때만 우선 검토할 기능

- 게임 로그인 - 유저 식별자 받기
- 게임 리더보드
- 게임 프로모션
- 화면 방향 설정하기
- 화면 항상 켜짐 설정하기
- 오디오 포커스 변경 콜백

## 3. RN 프로젝트에서는 제외되는 기능

공식 표 기준 `WV 전용`이므로 현재 RN 프로젝트에서는 제외한다.

- iOS 스와이프 설정하기
- WebView 속성 제어하기
- 배너 광고(WebView)

## 4. 현재 프로젝트에서 우선순위가 높은 기능군

현재 프로젝트가 RN 기반이고, 아직 제품 기획이 고정되지 않았다는 전제에서
우선 검토 가치가 높은 기능군은 아래다.

### 기본 골격

- 라우팅
- 레이아웃
- 내비게이션 바
- Safe Area
- Overlay
- 저장소
- 환경 확인

### 비게임 서비스에서 자주 쓰는 기능

- 토스 로그인
- 토스 페이
- 인앱 결제
- 공유
- 권한 기반 디바이스 기능
- 분석

### 게임으로 확정될 때 추가되는 기능

- 게임 로그인
- 리더보드
- 게임 프로모션
- 방향 고정
- 화면 항상 켜짐

## 5. 해석 시 주의사항

- 공식 표의 `추천 대상`은 권장 분류이지 절대 제한은 아니다.
- 다만 `게임` 추천 기능은 게임이 아닌 서비스에서 우선순위가 낮다.
- `WV, RN`으로 되어 있어도 RN에서 동일한 구현 난이도라는 뜻은 아니다.
- 광고, 결제, 인증, 프로모션처럼 정책 민감 기능은 구현 직전에 개별 문서를 다시 확인해야 한다.

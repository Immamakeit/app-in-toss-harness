# Toss Integration Reference

## 목적

이 디렉터리는 Apps in Toss 서버 연동 문서를
업무 기준으로 다시 정리한 **참조용 문서 묶음**이다.

- 원문 소스: `developers-apps-in-toss.toss.im` 공식 문서
- 정리본 용도: 기획이 정해진 뒤, 필요한 연동 범위를 빠르게 찾고 구현 기준을 맞추기
- 우선순위: 이 문서는 **정리본**이다. 원문과 충돌하면 항상 공식 원문을 우선한다.

## 분류 기준

- `common-protocol.md`: 모든 서버 API가 공유하는 규격
- `sdk-capability-matrix-rn.md`: 현재 RN 프로젝트 기준 SDK 기능 해석표
- `login.md`: 토스 로그인, 토큰 발급/재발급, 사용자 정보 조회, 연결 해제
- `tosspay.md`: 토스페이 결제 생성, 인증, 실행, 환불, 상태 조회
- `iap.md`: 인앱결제 상품 조회, 결제, 주문 복원, 주문 상태 조회
- `promotion.md`: 게임/비게임 프로모션 지급 방식과 운영 주의사항
- `smart-message.md`: 테스트 메시지, 메시지 발송

## 문서 작성 규칙

앞으로 새 문서가 들어오면 아래 기준으로 같은 디렉터리에 추가한다.

1. **공통 규격**인지 **업무별 연동**인지 먼저 판단한다.
2. 업무별 문서는 아래 형식을 유지한다.
   - 업무 목적
   - 선행 조건
   - 연동 흐름
   - 연동 규격
   - 예외 처리
   - 운영 메모
   - 원문 근거
3. 현재 문서셋에 없는 세부 스펙은 추측하지 말고 `추가 확인 필요`로 남긴다.

## 빠른 선택 가이드

- 사용자 식별, 동의, 토큰, 사용자 정보: `login.md`
- 실제 결제/환불/대사: `tosspay.md`
- 앱마켓 인앱 상품, 미결 주문 복원: `iap.md`
- 토스 포인트 지급 이벤트: `promotion.md`
- 사용자 메시지/푸시 템플릿 발송: `smart-message.md`
- 도메인, mTLS, 방화벽, 응답 포맷: `common-protocol.md`
- 현재 RN 앱에서 무엇이 가능한지 1차 분류: `sdk-capability-matrix-rn.md`
